# The Phage is Rage

A kid-friendly p5.js project introducing bacteriophages through three planned levels:

- `anatomy.html` — meet the parts of a phage
- `hunting.html` — learn how phages find their bacterial hosts
- `phage_saviors.html` — explore why phages matter to science

The level pages currently provide illustrations and educational introductions; interactive level activities are not implemented yet.

Open `index.html` in a browser to explore the screens. The p5.js sketch and Nunito font load from CDNs, so an internet connection is needed for those assets.
